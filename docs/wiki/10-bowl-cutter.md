# Bowl Cutter

Use Bowl Cutter to create the toolpath for a bowl-shaped recess. Treat the output as a generated G-code program: verify cutter, stock size, depth, work zero and safe clearance before running it.

![Bowl Cutter tool](/images/ooznest-control/55-bowl-cutter-clean.png =100%x)

Generate the toolpath, open it in the Editor, inspect it in 3D Preview, and only then prepare the physical machine.
