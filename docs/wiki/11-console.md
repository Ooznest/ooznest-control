# Console

The Console exposes direct communication with the controller. Use it for diagnosis and commands you understand; it is not a beginner-safe substitute for the normal controls.

![Live Console, full application view](/images/ooznest-control/65-console-live-fullscreen.png =100%x)

## Controls

- **Terminal output:** shows controller replies, status and errors.
- **Command input:** sends a line directly to the controller when submitted.
- **Toolbar actions:** manage the visible terminal information; use them before collecting support evidence if required.

{.is-warning}
> Never paste commands from an unknown source. Direct commands can alter settings or cause motion.
