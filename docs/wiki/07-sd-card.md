# SD Card

The SD Card tab manages files stored on the controller's card. It is separate from the Editor so you can inspect, upload and run controller-side files.

![Live SD Card tab with controller files](/images/ooznest-control/66-sd-card-live-root.png =100%x)

## Browse and preview

Use the breadcrumb to move through folders and select a file to inspect it before starting a controller-side job.

![Preview controller-side file confirmation](/images/ooznest-control/67-sd-card-preview-confirmation.png =100%x)

## Upload

Upload from the Editor after reviewing the file. Use a meaningful filename so the operator can identify it at the machine.

## Format

Format removes the card's contents. Confirm that the card is the intended target and that any needed job files are backed up before approving the format prompt.

![Format SD card confirmation](/images/ooznest-control/68-sd-card-format-confirmation-live.png =100%x)
