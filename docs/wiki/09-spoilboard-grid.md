# Spoilboard Grid

Use Spoilboard Grid to generate a marked grid on a spoilboard. Check the real usable cutting area and clamp locations before running the generated program.

![Spoilboard Grid tool](/images/ooznest-control/54-spoilboard-grid-clean.png =100%x)

Set the grid dimensions, spacing and safe clearance. Generate the G-code, then inspect it in the Editor and 3D Preview before use.
