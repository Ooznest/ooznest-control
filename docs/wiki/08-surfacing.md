# Surfacing

Use Surfacing to generate a levelling program for stock or spoilboard. It creates G-code; it does not check clamps, material or cutter installation.

![Surfacing tool](/images/ooznest-control/49-surfacing-tab.png =100%x)

1. Measure the actual area to cut.
2. Set cutter diameter and overlap.
3. Set a conservative cutting depth, feed and **Safe Z Clearance (mm)**.
4. Generate the program and inspect it in the Editor and 3D Preview.
