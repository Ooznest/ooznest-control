## Capture provenance

The first-connection, firmware-complete, WorkBee Z2 dashboard, live GRBL settings, Gamepad and Edit Macro images were captured with a real WorkBee Z2 controller attached. Wi-Fi fields are intentionally blank. Alarm/error images, where used, are labelled as simulated UI states and must never be treated as machine-operation instructions.
