First safe job

The short sequence to follow before the first WorkBee Z2 movement and before every new job.

Guide homeMachine controlsWorkspace tabsServiceScreenshots

Before connecting

  1. Fit the cutter with power isolated, secure the material, remove spanners and keep the emergency stop reachable.
  2. Check the intended cutter, material, clamps, work envelope and Safe Z clearance.
  3. Have the correct controller firmware/configuration and the G-code file’s expected units/WCS available.

The sequence

  1. Connect. Stop if the app remains UNKNOWN or reports an error.
  2. Home. Clear the travel and use Home All when the WorkBee procedure requires a repeatable machine reference. Homing is not work zero.
  3. Choose WCS. Select the coordinate system expected by the file, normally G54 for a first job.
  4. Set work zero. Jog to the intended material origin and use Set Zero All or the individual zero controls.
  5. Load and inspect. Check filename, dimensions, origin, depth, toolpath and Safe Z in 3D Preview.
  6. Run cautiously. Confirm clamps and clearance, then Run Job. This starts real machine motion.
  7. Stop on disagreement. Use the emergency stop if necessary and record the exact status/alarm and last action.
