Scope and version

This guide is based on the hosted/local Ooznest Control UI observed at v1.0.174. Firmware, machine dimensions, cutter data, coordinates and example G-code must be checked against the actual WorkBee Z2 build; screenshots are interface references, not machine settings.

Never copy screenshot values blindly. Demo macros, SD files and toolpath numbers are illustrative. A controller connection is not proof that the machine is safe to run.
